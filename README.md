# 🔍 MINI SHERLOCK — The Detective Trials

*A text-based detective game built with Python.*

> Every clue matters. Every suspect has a story. Can you uncover the truth?

## 📖 About the Project

**MINI SHERLOCK — The Detective Trials** is my first self-coded Python project. It is an interactive, text-based detective game where players investigate mysteries by interrogating suspects, examining clues, and making accusations.

I started this project to move beyond solving individual coding exercises and learn how to turn an idea into a working software project. My goal is to strengthen my programming fundamentals, improve my logical thinking, and understand how different parts of a program work together.

This project is being developed step by step using the Python concepts I have learned so far.

## 🎮 The Story

A priceless diamond has disappeared from a mansion during a grand party. Three suspects are under investigation:

- 🕵️ **The Personal Assistant**
- 💼 **The Business Partner**
- 🌿 **The Gardener**

Each suspect has a statement, and the clues may reveal who is hiding the truth.

Your mission is to interrogate the suspects, study the evidence, and identify the real thief.

But this is only the beginning. More mysteries and tougher investigations are planned!

## 🏆 Scoring System

Each mystery is worth a maximum of **10 points**.

| Player's decision | Points earned |
|---|---:|
| Correct accusation | 10 |
| Wrong accusation | 5 |

The planned full game will contain four mysteries, giving a maximum score of **40 points**.

Players will need at least **35/40 points** to earn the legendary **SHERLOCK BADGE**.

*The full four-level scoring and badge system is still planned.*

## 🚀 How to Run the Project

### Requirements

- Python 3 installed
- Git installed (optional, if cloning the repository)
- A terminal or code editor such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/shreyasv0719/mini-sherlock-first-own-coded-.git
```

### 2. Open the Project Folder

```bash
cd mini-sherlock-first-own-coded-
```

### 3. Run the Game

```bash
python3 main.py
```

If your system uses `python` instead of `python3`, you can run:

```bash
python main.py
```

Follow the instructions displayed in the terminal to play Level 1.
